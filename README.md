## 🏛️ Overview

**Law Entrance Master India** is an open, modern, bilingual (English + Hindi), interactive web application designed for students preparing for India's premier law entrance examinations:
1. **CLAT — Common Law Admission Test (UG & PG)**
2. **AILET — All India Law Entrance Test (UG & PG)**

Engineered around the comprehensive student preparation pipeline:
$$\text{SYLLABUS} \longrightarrow \text{CONCEPT} \longrightarrow \text{BOOKS} \longrightarrow \text{CURRENT AFFAIRS} \longrightarrow \text{PRACTICE} \longrightarrow \text{PYQ} \longrightarrow \text{MOCK} \longrightarrow \text{ANALYSIS} \longrightarrow \text{REVISION} \longrightarrow \text{EXAM} \longrightarrow \text{SCORE} \longrightarrow \text{COUNSELLING} \longrightarrow \text{NLU}$$

## ⚡ Core Features & Capabilities

### 1. 2027 Official Exam Architecture
* **CLAT 2027 UG**: 120 Questions • 120 Marks • 120 Minutes • -0.25 Negative Marking • Offline Pen & Paper (OMR).
  * English Language (22–26 Q, ~20%)
  * Current Affairs & General Knowledge (28–32 Q, ~25%)
  * Legal Reasoning (28–32 Q, ~25% — *No prior legal knowledge required; passage-based principle-fact application*)
  * Logical Reasoning (22–26 Q, ~20%)
  * Quantitative Techniques (10–14 Q, ~10% — *Class 10 standard data interpretation*)
* **AILET 2027 UG**: 150 Questions • 150 Marks • 120 Minutes • -0.25 Negative Marking • Speed-intensive (~48s per question).
  * Section A: English Language (50 Q, 50 Marks)
  * Section B: Current Affairs & General Knowledge (30 Q, 30 Marks)
  * Section C: Logical Reasoning (70 Q, 70 Marks — *incorporates legal reasoning aptitude*)
* **Dynamic Comparison Matrix**: Side-by-side comparative analysis of syllabus, exam patterns, tie-breaking criteria, negative marking, and timing pressure.

### 2. Specialized Cognitive & Skill Labs
* **Passage Lab (~450 Words)**: Interactive evidence highlighter, sentence annotation, paragraph breakdown, and comprehension verification.
* **RC Lab (Reading Comprehension)**: Dynamic WPM (Words Per Minute) pace-setter (150–400 WPM) with comprehension retention checks.
* **Legal Reasoning 6-Step Lab**:
  1. Read factual matrix
  2. Extract applicable legal principle strictly from passage
  3. Identify core issue
  4. Formulate test of law
  5. Apply rule to facts without external bias
  6. Reach logically sound conclusion
* **Logical Reasoning Lab**: Argument structure decomposition (Premise, Assumption, Conclusion, Strengthening, Weakening, Flaw identification).
* **Quant & DI Formula Lab**: Caselet math, ratios, percentages, profit & loss, mensuration, and visual data interpretation.
* **Rapid-Fire Speed Lab**: Real-time timer challenge training for AILET's 48-second cadence.

### 3. Legal & Constitutional Knowledge Hub
* **Landmark Supreme Court Judgments**: 7-Judge & 5-Judge Constitution Bench verdicts (e.g., SC/ST sub-classification 2024, BNS/BNSS/BSA transition, Electoral Bonds invalidation, Right against adverse climate effects under Arts 21 & 14, Arbitration unstamped agreements, DPDP Act 2023, Article 370 abrogation).
* **Indian Constitution Master**: Interactive explorer covering Preamble, Articles 14–18 (Equality), Articles 19–22 (Freedoms), DPSPs, Fundamental Duties, Writs (Arts 32 & 226), and the Basic Structure Doctrine.
* **Legal Maxims Master (50+ Latin Maxims)**: Phonetics, literal English translations, Hindi definitions, landmark case laws, and sample questions.
* **Important Legal Terms & Writs**: Procedural, criminal, tort, contract, and constitutional jurisprudence dictionary.

### 4. Verified Question Bank & Practice Engine
* **1,480+ Real, Database-Computed Questions**: Every count is computed dynamically from real datasets.
* **Strict Source Transparency**: Questions are tagged as `VERIFIED PYQ`, `ORIGINAL`, or `PYQ-STYLE`.
* **Multi-Filter Engine**: Filter by Section, Topic, Exam, Difficulty, and Source.
* **Detailed Step-by-Step Rationales**: Explains why the correct option holds and why each distractor is incorrect.
* **One-Click Error Logging**: Directly send any missed or confusing question to the Error Notebook.

### 5. Full Mock Test Engine
* **Authentic Exam Simulation**: Full CLAT (120 Q, 120m) and AILET (150 Q, 120m) mocks, plus focused sectionals.
* **4-State Question Palette**: Not Visited, Not Answered, Answered, Marked for Review.
* **Exam Controls**: Sectional switching, countdown timer with visual warnings, confirm submission modal, and auto-submit upon timer expiry.
* **In-Depth Scorecard & Analytics**: Raw score, negative marks penalty, net score, accuracy %, time distribution per section, and error breakdown.

### 6. 10-Category Error Notebook
Tracks and categorizes preparation mistakes to eliminate score leakage:
1. *Factual Misreading*
2. *Principle Extrapolation*
3. *Extreme Option Trap*
4. *Calculation / Quant Slip*
5. *Time Pressure Rush*
6. *Vocabulary Misinterpretation*
7. *Premise-Conclusion Confusion*
8. *Out-of-Scope Assumption*
9. *Negative Phrasing Miss*
10. *Overthinking / Second Guessing*

### 7. National Law University (NLU) Explorer & Admissions
* **26 Consortium NLUs + NLU Delhi**: Detailed profiles with NIRF rankings, student capacity, fee structures, state quotas, and historical cutoff trends (labeled `HISTORICAL DATA`).
* **Side-by-Side NLU Comparison**: Compare up to 3 NLUs simultaneously across fees, seats, tier, and placement trends.
* **Counselling & Seat Allocation Guide**: Step-by-step guidance on **Freeze**, **Float**, and **Exit** mechanisms, seat confirmation fees, and document verification.
* **Zero-to-Exam 11-Level Roadmap**: Comprehensive roadmap spanning Foundation (L0) to Exam Day Execution (L10).

### 8. Spaced Flashcards & Current Affairs
* **9 Thematic Flashcard Decks**: Legal maxims, constitutional articles, landmark cases, contract terms, tort doctrines, and vocabulary.
* **Timed Current Affairs Quizzes**: Daily 10, Daily 20, Weekly 50, and Monthly drills.

## 🚀 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/raghavendra-exp/law-entrance-master.git
   cd law-entrance-master
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build production bundle**:
   ```bash
   npm run build
   ```

5. **Preview production build locally**:
   ```bash
   npm run preview
   ```

## 🌐 Deployment to GitHub Pages

The project includes an automated GitHub Actions CI/CD workflow (`.github/workflows/deploy.yml`).
When changes are pushed to `main`:
1. Dependencies are cleanly installed via `npm ci`.
2. TypeScript types and production assets are compiled via `npm run build`.
3. The `./dist` directory is uploaded and deployed to GitHub Pages automatically.

To enable GitHub Pages in your repository settings:
1. Navigate to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select **GitHub Actions**.
